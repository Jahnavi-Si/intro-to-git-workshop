# Intro to Git & GitHub Workshop 💻

Welcome to the **ACM-W girls.code() Intro to Git & GitHub Workshop!**

This repository contains a simple HTML and CSS website that will be used to practice the basics of Git and GitHub.

## Workshop Goals

In this workshop, you will learn:

- Forking a repository
- Cloning a repository
- Creating a branch
- Making changes
- Committing changes
- Pushing changes to GitHub
- Creating a pull request

## Project

Personalize the webpage by filling in the blanks in `index.html` with information about yourself!

To view your webpage, open `index.html` in your web browser. After making changes, save the file and refresh the page.

## Files

- `index.html` — Website content
- `style.css` — Website styling

## Have Fun! 

Experiment, make changes, and get comfortable using Git and GitHub!
